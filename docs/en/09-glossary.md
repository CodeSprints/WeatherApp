# Glossary

**Composable** — a Vue function that bundles state and logic and can be used in
many components. Here it is `useWeather`.

**UV index** — a number from 0 to 11 and above describing the strength of
ultraviolet radiation. The higher it is, the faster skin burns.

**Air quality index (AQI)** — a rating of air cleanliness from 1 to 5, where 1 is
good air and 5 is very poor air.

**Probability of precipitation (pop)** — a value from 0 to 1 giving the chance of
rain or snow in a given hour. The interface shows it as a percentage.

**Breakpoint** — the screen width at which the layout changes.

**Ref** — a value holder in Vue. Changing the value redraws the elements that use it.

**Service** — a module with logic independent of the view, for example data fetching.

**Feels-like temperature** — temperature adjusted for wind and humidity.

**WCAG** — the set of guidelines for web content accessibility. Level AA is the
commonly adopted requirement.

**Component event (emit)** — the way a component passes information to its parent.
