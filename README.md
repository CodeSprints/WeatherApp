# Vue Web Template

## Requirements

* Node.js 20.19+ or 22.12+
* npm 10+

## Getting Started

```bash
npm install
npm run dev
```

## Quality Checks

```bash
npm run typecheck
npm run lint
npm run format:check
npm test
npm run build
```

Before getting started, change the `name` in `package.json`, the title in `index.html`, and the content of the example views. Tailwind CSS 4 works through the Vite plugin and `@import 'tailwindcss'` — no configuration file is required.
