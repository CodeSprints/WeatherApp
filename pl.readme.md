# Vue Web Template

## Wymagania
- Node.js 20.19+ lub 22.12+
- npm 10+

## Start
```bash
npm install
npm run dev
```

## Kontrola jakości
```bash
npm run typecheck
npm run lint
npm run format:check
npm test
npm run build
```

Przed rozpoczęciem zmień `name` w `package.json`, tytuł w `index.html` i treść przykładowych widoków. Tailwind CSS 4 działa przez plugin Vite i `@import 'tailwindcss'` — nie wymaga pliku konfiguracyjnego.
